Example map — evenly spaced index contours

Every field ramps its index linearly, with band width proportional to its level (30 m per level), so contour lines are evenly spaced everywhere: an n = 2 field has twice the transition of an n = 1.41 field. Contours of the composed refractive index (union rule, linear bands). Thin lines every third of a level, all the same weight; lines sit at whole thirds of a level, so each field's innermost contour lands exactly on its core edge (bold), where the index reaches its full value and sight is blocked. Thin air teal, thick air violet; light stepped fill between lines. The arena edge is a high-index field too.
